# quickstart-00

Versi mentah (raw, tanpa SDK) dari quickstart TypeSafe Jev via OpenRouter.
File asli dari dokumentasi TypeSafe, diterjemahkan ke Bahasa Indonesia.

## File
- `jev-quickstart-00.ts` — versi Bahasa Indonesia
- `jev-quickstart-00-en.ts` — versi Bahasa Inggris (asli)

## Cara jalan
```bash
npm install
export OPENROUTER_API_KEY=<key>
npm run q00      # Indonesia
npm run q00-en   # Inggris
```
